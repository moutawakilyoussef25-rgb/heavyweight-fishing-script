Frequently asked questions

What players ask most about the Heavyweight Fishing Script.

Is the Heavyweight Fishing Script free to use?
Yes. The Heavyweight Fishing Script is free and open source. You can download the latest Windows build from the download page and inspect the source on GitHub at no cost.
Does it work on Windows 10 and Windows 11?
The script is built specifically for Windows 10 and Windows 11. It runs as a standalone desktop application and does not require any additional runtime or external dependencies to be installed.
Can I run multiple accounts at the same time?
Yes. The multi-account macro loop lets you register several accounts with individual profiles and cycles through them automatically, so you can scale your AFK farm grind across your full roster.
How does fish rarity ESP and zone detection work?
Fish rarity ESP reads the on-screen fishing state and overlays a rarity indicator, while zone detection watches the zone marker and repositions your character to keep casting in high-yield spots. Both run locally and can be toggled independently from the settings panel.
